# Knowledge Base (`docs/`)

Durable, human-facing documentation lives here: architecture, PRDs, feature specs, guides.

Lessons and conventions the agent must re-read belong in project memory. Legacy
projects use `.resonance/02_memory.md` and `.resonance/memory/`. Projects with
`.resonance/ledger/` use the ledger as the authority for its five typed record
families, then keep prose summaries as derived views. Docs are durable
explanation, not runtime memory.
