# Research Synthesis Protocol

> **Objective**: Turn useful evidence into a decision-ready finding.

## 1. Frame and test

State the question or, when testable, a hypothesis and prediction. Choose a check that fits the claim: run or reproduce executable behavior, compare observations, consult the governing primary source, or confirm with the responsible owner. Do not imply that every research question needs a benchmark or that every claim needs the same source count.

## 2. Compare options

Use a matrix when criteria or options are hard to compare in prose. Include only options that could change the decision.

| Criteria | Option A | Option B | Option C |
| :--- | :--- | :--- | :--- |
| **Cost** | Free | $50/mo | Enterprise |
| **Complexity** | Low | High | Medium |
| **Risk** | Low | Low | High |

Replace example values with evidence or label them as unknown. Do not present illustrative scores as findings.

## 3. Verify and synthesize

Prefer the most authoritative source for the claim. One applicable primary source may be sufficient; seek independent corroboration when uncertainty, contradiction, or consequence warrants it. State scope, conflicts, and remaining uncertainty. Run code only when it can answer the question and the run is relevant and available.

## 4. Documentation type

- **Tutorial**: Learning-oriented steps to get started.
- **How-To**: Problem-oriented steps to solve a specific task.
- **Reference**: Information-oriented facts and specifications.
- **Explanation**: Understanding-oriented context and reasons.

Keep one document focused on its reader's job.
