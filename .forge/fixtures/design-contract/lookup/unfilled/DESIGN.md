## Workspace table pattern

Use the shared table with filters in the result toolbar. Keep row inspection in the shared contextual drawer at the supported wide layout. At the existing narrow-layout selector, use the record route. The table and drawer are implemented in `src/workspace/RecordTable.tsx` and `src/workspace/RecordDrawer.tsx`.
